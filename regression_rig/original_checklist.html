Setup — read before starting
  • Serving the app. Either http://localhost / the Pages URL (bluebrazelton-dotcom.github.io/DidaRec), or file:// (double-click index.html). file://-Chrome caveat: file:// origins never persist a getUserMedia grant, so Chrome's in-app device dropdowns can't show real names there — every grant re-prompts via Chrome's own pop-up. Expected, not a bug (Known Limitation #9). Test named-dropdown items over localhost or the Pages URL.
  • Simulating a crash. Kill the tab (Ctrl+W) or the browser process from Task Manager mid-recording. Reopen the app the same way (same origin/path) — recovery reads from IndexedDB, which is origin-scoped.
  • Resetting once-ever flags. Clear site data for the app's origin (DevTools → Application → Clear site data). Resets: audioHintShown (v1.25 hint), micEnumAnonymized / camEnumAnonymized, pipLayout + quality preset, and the IndexedDB itself (recovery sessions, caption drafts) — also your "start completely clean" reset.
  • Firefox download setting. For cancel/failed-download tests, set "Always ask you where to save files" (Settings → General → Downloads) so a Save-As dialog actually appears to cancel.
  • Stage: a working mic; a second window/app to share (plus a different one for Change-screen tests); a couple of previously-recorded .webm files for the caption section (or record one early and reuse it); optional VB-Cable / Stereo Mix (loopback spot-check only); optional spare camera or mic (hot-plug).
  • Save-flow reminder (every save below): Chrome/Edge — the File System Access dialog must be confirmed for a save to count. Firefox — downloads immediately, then the in-app "Downloaded — did it arrive?" bar must be resolved. Don't skip resolving that bar when a Firefox item says "save."
  • Order: both browsers, Firefox first, for every section. One Chrome-family pass covers Edge.
